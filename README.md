# Модальные конструкции в турецком — Alterna Timur

Гайд по `-abil/-ebil`, `-malı/-meli`, `lazım`, `gerek`, `zorunda` и `şart`: как сказать «могу», «надо»,
«вынужден» и «без вариантов». Истории в рубленом ритме «У меня был TÖMER. В TÖMER была доска…»,
интерактивы, озвучка каждой турецкой формы. В конце — переход на платформу **Alterna Timur A0 → C1**.

Дизайн — по мотивам кейса Sednor IT Company с Behance: монохромная фотография, туман и зерно,
узкий гротеск капсом (Oswald), неоново-жёлтый акцент, кнопки в `[ скобках ]`, номера разделов `[ 01 ]`,
«мятые» карточки, стопка карточек-кейсов со счётчиком `[ 01 / 14 ]`, гигантская CTA в подвале.
Все «фото» нарисованы кодом (SVG): склон с путником, горы, лес в тумане, облака.

## Разделы

1. **-abil / -ebil** — история про доску в TÖMER, формула, карточки-перевёртыши `gelebilirim / gelemem / gelmeyebilirim`, вежливые просьбы из консульства
2. **-malı / -meli** — врач и бег в +42
3. **lazım · gerek** — зарядка в магазине электроники, две конструкции, сборщик «кому + что + lazım/gerek» с ловушкой «Ben su lazım»
4. **zorunda · şart** — Göç İdaresi и окно номер семь
5. **Шкала обязательности** — гора из шести ступеней: `Gidebilirsin → Gitsen iyi olur → Gitmelisin → Gitmen lazım → Gitmek zorundasın → Gitmen şart`
6. **Конструктор** — 8 глаголов × 8 режимов × 6 лиц; суффиксы падают кирпичами, внизу объяснение (гармония, буфер y, t → d, исчезающий bil)
7. **olabilir · olmalı** — измеритель уверенности со стрелкой
8. **Olur · Olmaz** — мини-чат в аудитории TÖMER
9. **Тест** — 8 ситуаций, конфетти от 6/8
10. **Шпаргалка**

Дальше продающий блок: грамматика и лексика, история «сорок вкладок», цифры платформы, стопка из 14 карточек
с фильтрами, 5 записей экрана (ч/б, цвет появляется при прокрутке), 13 скриншотов с телефона, «3 темы из 7 блока
уже пройдены», цена с разбивкой, выбор уровня, FAQ, финальная CTA и липкая плашка на мобиле.

## Формы и озвучка

```bash
python3 tools/forms.py
bash tools/gen-audio.sh
```

`forms.py` — единственный источник форм: тот же расчёт идёт и в тренажёр (`forms.js`), и в озвучку.
Скрипт озвучки пропускает готовые файлы, поэтому повторный запуск доделывает только новые.

Голос **синтезированный** — `Yelda` из macOS, не запись человека. Чтобы поставить живой голос, положи mp3 с тем же
именем в `audio/tr/`. Если файла нет, сайт включает синтез речи браузера.

## Локальный запуск

```bash
python3 -m http.server 8834
```

Открыть `http://localhost:8834`. Через `file://` озвучка не заработает.
